EVENTS ON #jjg-try-it
change: { id, value } for every plugin parameter. Choices report the index, switches true or false, knobs in plugin units. transport: { action: play, stop or clip, clip: the clip id }.
ENGINE HOOKS
el.tryIt.ready() ends the loading state, el.tryIt.fail(msg) shows the fallback, el.tryIt.getParams() reads all {{ paramCount }} values, el.tryIt.getClip() reads the clip. Low Lat is always on and is not reported; mono input is not exposed. Turn the simulate tweak off when wiring.
