EVENTS ON #jjg-drive-try-it
change: { id, value } for every plugin parameter. Choices report the index, switches true or false, knobs in plugin units. transport: { action: play, stop or clip, clip: the clip id }.
ENGINE HOOKS
el.tryIt.ready() ends the loading state, el.tryIt.fail(msg) shows the fallback, el.tryIt.getParams() reads every value, el.tryIt.getClip() reads the clip. Turn the simulate tweak off when wiring.
CLIP SLOTS
Vocals (the six JJG Vocals clips), guitars, bass, drums and keys, the same sources as Salt. 20 second loops, the pad is 14. The transport event carries the clip id and getClip() adds the group.
