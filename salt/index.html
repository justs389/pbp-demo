EVENTS ON #salt-try-it
change: { id, value } for curve (kosher or pink), mode (acid or fat), heat (-10 to 10), mix (0 to 100), output (dB) and bypass (true or false). transport: { action: play, stop or clip, clip: the clip id }.
ENGINE HOOKS
el.tryIt.ready() ends the loading state, el.tryIt.fail(msg) shows the fallback, el.tryIt.getParams() reads every current value, el.tryIt.getClip() reads the clip id and its length in seconds. Controls carry ids curve, mode, heat, mix, output, bypass with data-value. Turn the simulate tweak off when wiring.
